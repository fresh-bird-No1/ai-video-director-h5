# 末尾追加一镜

## 职责

- 只新增一镜，接在本集已有分镜的最后一镜之后。
- 通读整张分镜表后写新镜，让新镜在人物、场景、道具、叙事节奏和时间线上都接得住。
- 不重写已有镜头，不重排整集，不输出第二镜。
- 不改剧情与台词，不新增资产卡之外的角色。

## 读什么

- 本集全部已有分镜，从第 1 镜读到末镜；运行时字段是 `board`，旧提示词里也称 `existingShots`。重点确认末镜结束在什么动作、情绪、声音和画面上。
- 本集剧本，确认末尾还有哪个动作、台词或钩子没有落到镜头上。
- 角色卡、场景卡、道具卡、站位卡，保证新镜引用的名称都存在。
- 角色卡的服装条目，保证 `costumes` 里的服装名称与服装卡完全一致。
- 用户对新增镜头的说明；没有说明时，以补强集末钩子为目标。
- 已有镜头的最大编号，用来确定新镜编号。

## 怎么写

### 1. 先读懂整张表

- 从第 1 镜通读到最后，不只看最后两三镜。
- 记下末镜的景别、机位、人物位置、光线、最后一个动作和最后一句台词。
- 确认哪些人物还在场、哪些道具还在画面里、哪些伏笔尚未收束。
- 新镜从末镜的落点继续，不重复已有画面，不回头补叙，也不另起一条无关剧情。

### 2. 编号与时长

- `no` 用用户指定的新镜号；用户没指定时，取已有最大镜号加一。必须是正整数，不占用已有编号，不从 1 重排。
- 本集原本没有镜头时，新镜 `no` 为 1。
- `durationSec` 为 1–15 的整数。
- 用 `beats` 写时间轴：每段 `start`、`end` 为整数秒，第一段 `start` 为 0，后段 `start` 等于前段 `end`，最后一段 `end` 等于 `durationSec`。
- 同时输出 `timeline`，一行一段，格式固定为 `0–2秒：内容`，必须由 `beats` 逐段生成。

### 3. 画面与台词

- `title`：2–8 个汉字，写动作或看点，不写镜号。
- `description`：一句话写本镜核心可见画面，不抄完整时间轴，不写人物心理。
- `shotSize`、`camera` 用下方固定中文枚举；景别词必须出现在 `beats[].text` 和 `framePrompt` 里。
- `dialogue` 只收本镜说出口的台词，格式只能是 `角色名：“原句”`，旁白写 `旁白：“原句”`。引号必须是中文双引号，原句不改，说话人必须是资产卡里的角色名。没有台词写 `""`。
- `beats[].text` 里，引号内才是台词，引号外写动作、神态和声音；招牌、字幕、短信文字用「」。
- `voiceNames` 按开口顺序列角色名，不含旁白；无人说话写 `[]`。
- `soundscape` 写整镜持续的环境音；单秒动作声写进对应 `beats.text`。
- `framePrompt`：中文分镜图提示词，直呼角色名，含景别词，写清构图、位置、朝向、光线和关键道具，只描述静帧。
- `assets` 列本镜角色、场景、道具名称，全部来自资产卡；可另给 `characterNames`、`sceneName`、`propNames` 作 H5 兜底，名字必须一致。
- `costumes` 只写本镜需要指定套装的角色，格式 `角色名：服装名称`，服装名称必须与角色卡服装条目完全一致；不需要换装时为 `[]`。
- 一镜同框人数上限为 3 人。
- `mode` 只能取 `t2v`、`i2v`、`fl2v`、`r2v`，拿不准写 `r2v`。

### 4. 衔接判定

- `linkPrev` 只在一种情况下为 `true`：新镜与上一镜原本是同一个超过 15 秒的长镜头，被拆成相邻两段。
- 正反打、换景、换机位、换时段、硬切，一律 `false`。不要因为剧情接得上就标连续。
- 新镜是本集第 1 镜时必须 `false`。
- `linkPrev` 为 `true` 时，`continuity` 必须写清机位、运动方向、主体位置和动作如何接上一镜末秒，不能换机位。
- `transition`：`linkPrev` 为 `true` 写「连续」，否则写「切」；新镜放在集末收束时写「收束」，用户明确说后面还要接镜时按实际切法写。

### 5. 红线

- `shots` 数组只能有 1 项，禁止顺带输出旧镜头或整集分镜。
- 新镜只承担一个连续调度，不把整场戏压进一镜。
- 不改已有镜头的任何字段，不改变已有镜头的转场与 `linkPrev`。
- 不改剧本台词，不新增情节，不替角色补原文没有的心理活动。
- 不新增资产卡里没有的角色；场景、道具只能用已有名称。
- 不写六段式视频提示词。

## 输出

只给一个 JSON 代码块，结构为 `{"kind":"board","data":{...}}`，`kind` 固定 `"board"`。`data` 包含：

- `episodeNumber`：整数集号。
- `shots`：只含新增的一镜，长度必须为 1。每项包含 `no`、`durationSec`、`shotSize`、`camera`、`description`、`timeline`、`beats`、`dialogue`、`assets`、`costumes`、`linkPrev`、`continuity`、`transition`，并补全 `mode`、`soundscape`、`voiceNames`、`framePrompt`，可选 `characterNames`、`sceneName`、`propNames`。
- 没有资产变化时，不要附带 `assetUpdates`；确需登记新场景或新道具时，按 H5 的 `assetUpdates` 结构另给。

## 硬性约束

- `shots` 只能有一条，禁止输出已有镜头。
- `no` 必须是用户指定镜号或现有最大值加一，为正整数。
- `durationSec` 为 1–15 的整数，最后一段 `beats[].end` 必须等于它。
- `beats` 首段 `start` 为 0，段段相接，不得跳秒。
- `timeline` 必须与 `beats` 一一对应，格式为「开始–结束秒：内容」。
- `shotSize` 只能取：大远景、远景、全景、中景、近景、特写、大特写。
- `camera` 只能取：固定、摇、移、跟、推、拉、升降、手持。
- 旧版英文分镜代码可作对照：`extreme-wide`/`wide`/`medium`/`medium-close`/`close`/`extreme-close` 对应大远景/全景/中景/中近景/近景/特写；`Static Shot`/`Push In`/`Pull Out`/`Zoom In`/`Zoom Out`/`Pan Left`/`Pan Right`/`Truck Left`/`Truck Right`/`Tilt Up`/`Tilt Down`/`Pedestal Up`/`Pedestal Down`/`Arc Shot`/`Tracking Shot`/`Shake Slightly`/`Shake Strongly`/`POV` 供旧字段识别。H5 的 `shotSize`、`camera` 仍写中文值，不混写。
- `linkPrev` 只在长镜头拆段时为 `true`，硬切、换景、换机位和本集第 1 镜必须 `false`。
- 台词只能用中文双引号包住原句，`dialogue` 与 `beats.text` 一致。
- `costumes` 的服装名称必须与服装卡完全一致，无换装时为 `[]`。
- 不新增资产卡外的角色，不改已有镜头，不写六段视频提示词。

## 交付前自检

- 是否真的只输出了一镜，`shots` 长度是否为 1。
- 编号是否接在现有最大值之后，没有重号或跳号。
- 新镜是否承接末镜落点，而不是重复旧画面或另起无关剧情。
- `beats` 是否从 0 连续覆盖到 `durationSec`，`timeline` 是否逐段对应。
- `dialogue` 是否为 `角色名：“原句”`，无台词是否为空字符串。
- `costumes` 是否为「角色名：服装名称」，名称是否能在角色卡服装条目中找到。
- `linkPrev`、`continuity` 与 `transition` 是否符合长镜头拆段或集末收束的判定。
- JSON 能否解析，是否没有注释与尾逗号。
