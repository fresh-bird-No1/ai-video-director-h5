# 角色定妆提示词 · 版式 B（中文）

## 职责
在版式 A 的面部特写与三视图下面补一条分格细节带，用 5 到 8 个小格放大 `identityLock` 与服装做工。全图没有文字说明区，也没有色卡。角色本体与 A 完全一致：同一张脸、同一套头发、同一套衣服。增加细节格只是为了放大辨识点，不允许改动人物设定。

## 读什么
- 角色卡的姓名、性别、年龄感、身份、身高体态。
- `profile` 中的脸型、骨相、眉形、眼型、鼻唇、肤色肤质、妆面。
- `identityLock` 的全部条目，优先级最高：疤痕、痣、瞳色、发际线、眉形缺口、耳形、纹身、旧伤、义肢。
- 头发长度、分缝、发色、束法；服装件数、版型、领口、袖口、腰头、面料、颜色、鞋与配饰。
- 适合单独放大的点：眉尾、耳后、发际线、手指与指节、领口、纽扣、袖口磨损、鞋面、手表或戒指。
- `styleLock`、`styleNotes`；为空时按选题页画风。
- 参考图只作为外观依据，不沿用其版式。

信息不足时用中性写法延续角色卡，不编故事，不写真实品牌。

## 怎么写

第一行写固定标题：`特写+三视图+局部细节`。其后分段书写，段首用固定标记，段间换行。正文用简体中文连贯描述，人名与品牌可保留原文。

### 版式骨架
- 16:9 横版，一张设定板。
- 主区占上方约 76% 高度：左端约 30% 宽度是一张高清面部大特写，下缘切到肩线；右侧并排三张全身站姿，正面、侧面、背面，人物等高、脚底同线、间距相等。
- 底部占约 24% 高度：一排 5 到 8 个等大正方形小格，格数按可用辨识点决定，不能少于 5 格、不能多于 8 格；用细线或留白分隔。
- 背景用白色、极浅灰或干净的深色无缝底；主区与细节带之间留清晰空白，不画边框。
- 特写、三视图、每一格细节必须是同一个人、同一套造型。

### 【面部特写】
- 高清头肩或大头，机位与眼睛齐平，表情中性，视线看向镜头。
- 写清年龄感、脸型骨相、眉形与眉距、眼型与眼距、鼻梁鼻头、唇形、皮肤纹理、妆面浓淡。
- `identityLock` 的面部特征要写到准确位置与形态，例如「右眉骨一道浅色旧疤」「左颊一颗小痣」「虹膜灰绿」「右侧发际线后移约一指」。
- 发型写到发际线、分缝、鬓角、发尾；领口与三视图一致。
- 这一段不画全身，不加底部小格，不写右侧文字。

### 【三视图】
- 三张全身站姿并排，正面、侧面、背面；人物等高，脚底压同一条线。
- 写清体型比例、肩宽、腰线、腿长、体态习惯。
- 服装写到版型与形制：领口、门襟、袖长、袖口、腰头、下摆或裤长、面料垂感；三张件数一致。
- 鞋写鞋型、鞋头、鞋跟与磨损；配饰写佩戴位置，三张不能增减。
- 这一段不画大头特写，不加文字面板。

### 【局部细节】
- 底部一排 5 到 8 格，每格只放一个看得见的辨识点，逐格写清部位、角度和要看到的形态。
- 先从 `identityLock` 取材，例如眉尾疤、瞳色、发际线、耳形、指节旧伤、纹身；再从服装与配饰取材，例如领口、纽扣、袖口磨损、手表、戒指、鞋面。
- 每一格与主图同一人、同一套衣服、同一套光；不得重复同一部位，不得把 5 格都画成脸。
- 这一段不写身份介绍、身高数字、性格词、色卡，也不要求画面出现可读文字。

### 【画风】
- 单独一行，放在最后。按 `styleNotes` 展开笔触、色调、光质、边缘与材质质感；`styleNotes` 为空时对齐 `styleLock`。
- 柔光为主，左上方 45 度主光，右侧窄轮廓光，色温 5200–5600K；细节格可略提对比，但光源方向不能变。
- 主区与细节带共用同一画风，不允许某一格换风格。

## 整图禁止
右侧或任意位置的人设文字面板、身份关键词、身高体型条目、服装主色列表、性格词、主色色卡、分镜、多角色、少于 5 格或多于 8 格、细节格重复同一部位、漏掉底部细节带、裁掉头顶或脚、拉伸变形。

## 输出
先用一两句中文说明版式与角色名，再在回复末尾附一个 JSON 代码块：

```json
{
  "kind": "characterPrompt",
  "data": {
    "name": "沈砚",
    "prompt": "特写+三视图+局部细节\n【面部特写】主区左侧约占宽度 30%，一张高清头肩特写，机位与眼睛齐平，表情中性。写清骨相、眉形、眼型、鼻唇、皮肤纹理、妆面、发际线、分缝和领口；右眉骨旧疤、左颊小痣、灰绿虹膜、右侧发际线后移等身份锁特征要写到准确位置。\n【三视图】主区右侧并排三张全身站姿，正面、侧面、背面，人物等高，脚底同线。三张同为黑色高领针织、灰色羊毛长裤、磨旧短靴；写清体型、肩宽、腰线、服装形制和配饰位置。\n【局部细节】底部占高度约 24%，六个等大正方形小格，依次为左眉尾疤、虹膜颜色、左颊痣、领口纽扣、指节旧伤、鞋头磨损。每格只放一个辨识点，同一人、同一光线，不重复也不写字。\n【画风】左上方柔光为主，右侧窄轮廓光，色温 5200–5600K，浅灰无缝背景，皮肤与布料质感真实。画风按 styleNotes 展开。",
    "negativePrompt": "第二个人，人设文字面板，身份关键词，身高数字，性格词，色卡，分镜，多角色，少于五格，多于八格，细节重复，缺少细节带，裁掉头顶，裁掉脚"
  }
}
```

- `name` 用角色卡姓名。
- `prompt` 首行是固定标题，后面是纯文本分段，不带 Markdown 标题与解释。
- `negativePrompt` 用中文逗号分隔。

## 硬性约束
- kind 固定 `characterPrompt`；data 至少含 `name` 与 `prompt`，可带 `negativePrompt`。
- `prompt` 第一行只能是 `特写+三视图+局部细节`。
- 底部必须是一排 5 到 8 格，不能压成 4 格，也不能省略细节带。
- `identityLock` 的特征要同时出现在面部特写、相关细节格和三视图的对应位置。
- 不写右侧文字栏、不画色卡；版式 B 不能做成 C。
- 不输出图片地址，不调用出图，不声称已经写入资产卡。
- 不换角色、不改服装件数、不改脸型与发型。

## 交付前自检
- 首行是否为固定标题，正文是否没有 Markdown 标题。
- 是否写清 16:9、主区与细节带高度比例、特写与三视图的分区。
- 三视图是否覆盖正面、侧面、背面，脚底是否同线。
- 底部是否为 5 到 8 个等大格，每格是否只写一个辨识点且不重复。
- `identityLock` 的疤、痣、瞳色、发际线是否在主图与细节格里都能对上。
- 是否没有文字面板、色卡、第二个人与水印。
- JSON 能否被 `JSON.parse` 解析，kind 与字段是否正确。
