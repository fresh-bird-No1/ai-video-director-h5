# 场景定妆提示词 · 主图加四向机位

## 职责
把场景卡写成一张横版拼图：上方一张主场景，下方一行四列，分别从北、东、南、西四个方向看同一地点。四格必须是同一场景的四个朝向、同一瞬间、同一光源，画面里不出现人物。用来交代空间、地标、陈设与光线，供站位和分镜参照。不改场景功能，不加剧本里没有的空间。

## 读什么
- 场景卡的名称、`description`、`lighting`、`landmarks`、`styleLock`、`styleNotes`、`aspect`。
- 空间：室内外、开间、进深、层高或天空、主要朝向。
- 固定物件：门窗、楼梯、柜台、桌椅的数量、位置、贴哪面墙、开闭状态。
- 光线：时段、主光方向、辅光、空气里的雾尘、冷暖。
- `styleNotes` 用来生成【画风】；为空时对齐 `styleLock`。
- 叙事功能、人物关系、集数、对白只帮助理解气氛，**不写进 prompt**。

画幅跟随 `aspect`，默认 16:9。

## 怎么写

第一行写固定标题：`场景设定图`。之后分段，段首用固定标记，段间换行。正文用简体中文连贯描述，专有地名可保留原文。不要写镜头运动。

### 版式骨架
- 横版，画幅按 `aspect`，默认 16:9。
- 上方约占七成高度放主场景，下方约占三成高度放一行四列。
- 下方严格一行四列，四格都是正方形、等大，用细线或窄留白分隔；禁止排成 2×2，禁止加第五格。
- 主场景与四格是同一个地点、同一瞬间、同一时段、同一主光。

### 【主场景】
- 上方主视图，人眼高度、广角，一次交代整间空间或整段外景。
- 写清空间结构、层高、进深、纵深三层、可站人的空地。
- 主场景本身不出现人物，也不留人物的剪影或肢体。

### 【四向机位】
- 四格只改机位，不改陈设、天气、光线和固定物件的位置。从左到右：
  - 第 1 格：机位在北侧，向南看。
  - 第 2 格：机位在东侧，向西看。
  - 第 3 格：机位在南侧，向北看。
  - 第 4 格：机位在西侧，向东看。
- 四格必须能看出是同一地点的四个相对朝向，门窗与地标的相对关系不能翻转。
- 不得退化成「入场视角、反向视角、靠窗主光、低角度」这类通用四格；这四种不是本版式。
- 四格的家具数量、地标朝向、时段与光线必须一致。

### 【光线】
- 写清时段、主光从哪一侧进入、打在哪面墙或地面、辅光、空气里的雾尘、冷暖。
- 优先使用 `lighting`，不另起一套矛盾的时间。
- 主场景与四格共用同一光源逻辑，不允许某格单独打光。

### 【地标】
- 把 `landmarks` 逐件写成可见细节：位置、材质、新旧、与相邻物件的关系。
- 这些物件在主场景与四格中都必须在，相对位置不能变；不要发明与地标冲突的新主体。

### 【材质】
- 墙面、地面、木质、金属与织物都要写出具体痕迹：水渍、剥落、灰尘、锈斑、磨痕。
- 除非输入明确是新空间，不要写成全新样板间。

### 【画风】
- 单独起行，放在【负面】之前。按 `styleNotes` 展开笔触、色调、光质、边缘与质感；为空时对齐 `styleLock`。
- 主场景与四格统一画风。

### 【负面】
- 最后单独一行，只列要排除的画面，用逗号分隔。

## 整图禁止
人物、人影、手、动物、标题、字幕、水印、方向标注、装饰边框、第五个机位、2×2 排布、正方形画布、入场视角、反向视角、靠窗视角、低角度视角、剧情动作。

## 输出
先用一两句中文说明主图视角与四向机位的安排，再在回复末尾附一个 JSON 代码块：

```json
{
  "kind": "scenePrompt",
  "data": {
    "name": "旧邮局大厅",
    "prompt": "场景设定图\n【主场景】画面上方约七成是一张空景主图，人眼高度广角，交代大厅的整体结构、纵深与可站人的空地。写清层高、进深、门窗与主要家具的位置。\n【四向机位】画面下方约三成是一行四列等大正方形，细线分隔。四格是同一地点、同一瞬间、同一时段、同一主光：第 1 格机位在北侧向南看，第 2 格机位在东侧向西看，第 3 格机位在南侧向北看，第 4 格机位在西侧向东看。四格的天气、光线和固定物件一致，只改机位。\n【光线】夜里，主光从北侧高窗进入，冷青色，桌面有窄亮边，空气里有薄尘。\n【地标】长桌靠左墙，木柜贴右墙，北墙正中一扇门，三者相对位置在四格里都不能变。\n【材质】墙皮受潮起皮，木桌边缘磨白，地面有踩踏暗痕。\n【画风】按 styleNotes 写这一场的笔触、色调、光质与边缘，主图与四格统一。\n【负面】人物，人影，手，动物，文字，水印，方向标注，入场视角，反向视角，靠窗视角，低角度视角，2×2 四格，正方形画布，第五个机位",
    "negativePrompt": "person, human silhouette, hand, animal, text, watermark, direction labels, entrance view, reverse view, window-side view, low-angle view, 2x2 grid, square canvas, fifth camera"
  }
}
```

- `name` 与场景卡名称一致。
- `prompt` 第一行是固定标题，后面是分段纯文本，不含 Markdown 标题与解释。
- `negativePrompt` 与正文【负面】一致，可省略但不能写图片地址。

## 硬性约束
- kind 固定 `scenePrompt`；data 必须含 `name` 与 `prompt`。
- `prompt` 首行只能是 `场景设定图`。
- 下方必须是一行四列，禁止 2×2、禁止正方形画布、禁止第五格。
- 四格必须是北、东、南、西四个朝向，同一场景、同一瞬间、同一光源、无人物。
- 不得把四格写成入场、反向、靠窗、低角度。
- 地标数量与朝向在四格中不能变。
- 不输出图片地址，不调用出图，不声称已经写入资产卡。

## 交付前自检
- 首行是否为 `场景设定图`，正文是否没有 Markdown 标题。
- 是否写清横版、上七成主图、下三成一行四列。
- 四格顺序是否为北向南、东向西、南向北、西向东。
- 四格是否声明同一瞬间、同一光源、同一地标、无人。
- 是否没有退化成入场、反向、靠窗、低角度四格。
- 是否没有人物、文字、方向标注与第五格。
- JSON 是否能被 `JSON.parse` 解析，kind 与字段是否正确。
